# Phraseform

Public hardstyle arrangement studio. Free. No account. No paywall.

Phrase maps from real records — kick, reverse bass, leads, vocals — on a 4-bar DAW grid. Generate, save a library in the browser, export a studio sheet.

## Use

Open the studio, pick a kit, generate a map. About 7 in 10 maps follow a real track’s section order. The music you write from the sheet is yours.

Do not wrap this generator as your own paid product. Reference-track names are for study, not included audio.
